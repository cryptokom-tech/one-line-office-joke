`main.py` (Python 3.13, standard library only) writes one joke about office life to `/output/entry.txt`:

> The team-building trust fall was cancelled because nobody volunteered to catch Dave from Finance — and Dave volunteered to push.

The line is 128 characters, a single sentence on a single line: a team-building trust fall, a payoff nobody saw coming, and a second beat — the one person nobody trusts to catch is the one offering to push.
